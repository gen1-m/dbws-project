# Rendezvous - A simple website made with PHP, HTML, CSS, and JavaScript

This is a simple website made for the Databases and Web Services course durring our second year at JUB. It is meant to be a website where we needed to demonstrate what we learned on class on PHP and SQL and more on the full 'admin' experience. The original repository where we worked on is private, but here we have made a copy of it for it. ORIGINAL_README is the README we wrote for the original project.

## Login Credentials for the maintenance page (admin page)
- Username: admin
- Password: admin

You are then presented with all of the links which take you to the different pages of the website where you have full control on registering new users, adding events, moving users from one event to another, and so...

## Features

- Register new users
- Register new clubs
- Register new events
- Assign users as club participants, leaders, moderators or simple members
- Assign users to general events, club events or personal events
- Assign users as event hosts, participants or simple attendees

You can also: 

- Search for specific users, events. clubs and their club participants
